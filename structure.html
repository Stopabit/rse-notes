1  Structure of a RangedSummarizedExperiment

1.1 The big picture

A RangedSummarizedExperiment (RSE) is best imagined as a rectangular container where rows are genomic features (genes, transcripts, peaks…) and columns are samples. Every slot is row-indexed or column-indexed, so subsetting one slot automatically subsets all others.

Figure 1.1 — Anatomy of a RangedSummarizedExperiment.
The assay matrix is the centre; all other slots are indexed to its rows or columns.

1.2 The five core slots

Slot Accessor Class Indexed by Holds
assays assay() / assays() SimpleList of matrices rows & cols Count matrices, normalized values, log-CPM…
rowRanges rowRanges() GRanges / GRangesList rows Genomic coordinates of each feature
rowData rowData() DataFrame rows Gene symbol, biotype, GC content…
colData colData() DataFrame cols Sample ID, condition, batch, QC metrics…
metadata metadata() list — Experiment-level free text, parameters…
NoterowData vs rowRanges — what’s the difference?

In a RangedSummarizedExperiment, rowRanges() always returns a GRanges object containing the genomic coordinates.
rowData() returns the mcols() (metadata columns) of that same GRanges — i.e., the non-coordinate per-feature annotations.

In a plain SummarizedExperiment (no ranges), rowRanges() returns NULL and rowData() returns the full per-feature DataFrame.

1.4 Dimensions and names

An RSE always has two dimensions accessible via dim():

dim(rse)
# [1] 20000   8      # 20 000 genes × 8 samples

nrow(rse)   # number of features
ncol(rse)   # number of samples

rownames(rse)  # feature identifiers (e.g. Ensembl IDs)
colnames(rse)  # sample names
ImportantThe golden rule of RSE — subsetting is synchronised 
rse_sub <- rse[1:100, rse$condition == "treated"]

This simultaneously subsets:

  • the assay matrix(es) to rows 1–100 and treated columns
  • rowRanges to features 1–100
  • colData to treated samples only
  • rowData accordingly

You can never accidentally misalign rows and columns.

1.5 What does show() print?

When you type an RSE object name in the console, R calls show() and you see something like:

class: RangedSummarizedExperiment 
dim: 20000 8 
metadata(1): ''
assays(2): counts normcounts
rownames(20000): ENSG00000000003 ENSG00000000005 ...
rowData names(3): gene_id symbol biotype
colnames(8): S1 S2 S3 S4 S5 S6 S7 S8
colData names(4): Sample condition batch sex

Each line directly corresponds to one slot in the diagram above.
